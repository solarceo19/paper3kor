# paper3kor
구조와 공력을 동시에 만드는 사면체 풍력 구조

본 연구는 정20면체 내부에 형성되는 황금 그노몬 기반 날개 구조를
사면체(Tetrahedral) 구조로 확장하는 새로운 기하학적 접근을 제안합니다.

기존 평면형 날개와 달리, 각 사면체의 P점은
r-point(Q)에서 밑면 법선 방향으로 상승시킨 선이
기존 정20면체 edge와 만나는 교차점으로 정의됩니다.

이 구조는 다음과 같은 가능성을 제시합니다.

• 기존 미보강 링 구조 보강
• 하이브리드 Lift–Drag 공력 특성
• 저속 자가 기동과 고속 효율의 결합
• 정다면체 기반 구조-공력 통합 설계

GeoWind는 단순한 풍력발전기가 아니라,
기하학과 구조역학, 공기역학이 결합된 새로운 에너지 플랫폼을 지향합니다.
